# SMS Game Maker - Ejemplo de Juego

Este repositorio contiene un **proyecto de ejemplo** diseñado para ser utilizado con el motor y herramienta de desarrollo **[SMS Game Maker](https://juntelart.itch.io/sms-game-maker)** para Master System y Game Gear.

Sirve como plantilla y referencia práctica para aprender cómo estructurar pantallas, fases, gráficos y música en tus propios juegos.

---

## 🎮 Contenido del Proyecto

- **`screens/`**: Pantallas del juego (Intro, Pantalla de título, HUD, Game Over y Final) y su música correspondiente.
- **`stage_1/` & `stage_2/`**: Niveles de ejemplo con sus mapeados, tiles, sprites y música configurados.
- **`dist/`**: Carpeta de salida para las ROMs compiladas (`.sms` / `.gg`).

## 🚀 Cómo usarlo

1. Descarga e instala **[SMS Game Maker](https://juntelart.itch.io/sms-game-maker)**.
2. Abre este directorio como proyecto dentro de la aplicación.
3. Edita pantallas o fases a tu gusto y compila la ROM para probarla en tu emulador favorito de Master System / Game Gear o hardware real.
